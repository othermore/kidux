# IF : l'ordinateur décide

`IF` permet à l'ordinateur de choisir. Il regarde quelque chose, et si
c'est vrai, il fait ce qui vient après `THEN`. Sinon, il continue avec la
ligne suivante.

```basic keys=4,Enter
10 INPUT "COMBIEN FONT 2 + 2 ? "; A
20 IF A = 4 THEN PRINT "BRAVO !"
30 IF A <> 4 THEN PRINT "PAS TOUT A FAIT. CA FAIT 4."
```

`=` veut dire *est égal à*, et `<>` veut dire *est différent de*.

## Comparer

| Signe | Il veut dire |
|---|---|
| `=` | est égal à |
| `<>` | est différent de |
| `<` | est plus petit que |
| `>` | est plus grand que |
| `<=` | est plus petit ou égal à |
| `>=` | est plus grand ou égal à |

```basic keys=7,Enter
10 INPUT "TA NOTE, DE 0 A 10 ? "; M
20 IF M >= 5 THEN PRINT "C'EST REUSSI"
30 IF M < 5 THEN PRINT "CONTINUE, TU VAS Y ARRIVER"
```

## THEN et un numéro de ligne

Après `THEN`, il peut y avoir un numéro de ligne : si c'est vrai,
l'ordinateur saute à cette ligne. Cela fait une boucle qui se termine.

```basic keys=3,Enter,4,Enter
10 INPUT "COMBIEN FONT 2 + 2 ? "; A
20 IF A = 4 THEN 50
30 PRINT "ESSAIE ENCORE"
40 GOTO 10
50 PRINT "OUI ! 2 + 2 = 4"
```

## ELSE

`ELSE` dit quoi faire quand ce n'est pas vrai, sur la même ligne.

```basic keys=POISSON,Enter
10 INPUT "QUE MANGENT LES PINGOUINS ? "; F$
20 IF F$ = "POISSON" THEN PRINT "MIAM !" ELSE PRINT "NON, DU POISSON !"
```

> [point] Les mots sont comparés lettre par lettre, majuscules comprises :
> pour l'ordinateur, `poisson` n'est pas `POISSON`.

::: adult
`IF … THEN`, c'est là qu'un programme commence à réfléchir. Quand le
programme d'un enfant fait quelque chose d'inattendu, demandez-lui ce
que valait la condition à ce moment-là ; écrire les valeurs avec `PRINT`
est la façon dont les programmeurs le découvrent.
:::
