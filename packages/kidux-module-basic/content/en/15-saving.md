# Saving your programs

The program in the editor stays there when you close BASIC: it is there
again the next time. But only one program fits in the editor. To keep a
program, save it as a file.

- **Save** makes a file of the program. The computer asks where to keep
  it and what to call it: give it a name you will recognise, like
  `quiz.bas`.
- **Open** brings a saved file back into the editor.
- **New** empties the editor for a new program. It asks first, so that
  nothing is lost by mistake.

> [point] Programs are kept in your own folders, where you keep your
> drawings and your other work. They are yours.

## A program to save

Here is a little program to keep. Save it, press New, and then Open it
again.

```basic
10 REM MY FIRST SAVED PROGRAM
20 FOR N = 1 TO 3
30 PRINT "SAVED AND OPENED AGAIN!"
40 NEXT N
```

> [cheer] You have finished the first part of this guide. The next
> chapters teach more about BASIC, and how to draw, colour and make
> sounds.

::: adult
A `.bas` file is plain text: it can be opened in any text editor, sent
or printed. Programs saved here can also be run in many other BASICs,
with small changes.
:::
