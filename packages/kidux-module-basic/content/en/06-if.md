# IF: the computer decides

`IF` lets the computer choose. It looks at something, and if it is true,
it does what comes after `THEN`. If it is not, it carries on with the
next line.

```basic keys=4,Enter
10 INPUT "HOW MUCH IS 2 + 2? "; A
20 IF A = 4 THEN PRINT "WELL DONE!"
30 IF A <> 4 THEN PRINT "NOT QUITE. IT IS 4."
```

`=` means *is equal to*, and `<>` means *is different from*.

## Comparing

| Sign | It means |
|---|---|
| `=` | is equal to |
| `<>` | is different from |
| `<` | is smaller than |
| `>` | is bigger than |
| `<=` | is smaller than or equal to |
| `>=` | is bigger than or equal to |

```basic keys=7,Enter
10 INPUT "YOUR MARK, FROM 0 TO 10? "; M
20 IF M >= 5 THEN PRINT "YOU PASSED"
30 IF M < 5 THEN PRINT "KEEP TRYING, YOU WILL GET THERE"
```

## THEN a line number

After `THEN` there can be a line number: if it is true, the computer
jumps there. This makes a loop that ends.

```basic keys=3,Enter,4,Enter
10 INPUT "HOW MUCH IS 2 + 2? "; A
20 IF A = 4 THEN 50
30 PRINT "TRY AGAIN"
40 GOTO 10
50 PRINT "YES! 2 + 2 = 4"
```

## ELSE

`ELSE` says what to do when it is not true, on the same line.

```basic keys=FISH,Enter
10 INPUT "WHAT DO PENGUINS EAT? "; F$
20 IF F$ = "FISH" THEN PRINT "YUM!" ELSE PRINT "NO, FISH!"
```

> [point] Words are compared letter by letter, capitals too: `fish` is
> not `FISH` for the computer.

::: adult
`IF … THEN` is where a program starts to think. When a child's program
does something unexpected, ask what the condition was at that moment;
writing the values out with `PRINT` is how programmers find out.
:::
