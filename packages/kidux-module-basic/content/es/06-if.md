# IF: el ordenador decide

`IF` deja elegir al ordenador. Mira algo, y si es verdad, hace lo que
viene detrás de `THEN`. Si no lo es, sigue con la línea siguiente.

```basic keys=4,Enter
10 INPUT "¿CUANTO ES 2 + 2? "; A
20 IF A = 4 THEN PRINT "¡MUY BIEN!"
30 IF A <> 4 THEN PRINT "CASI. SON 4."
```

`=` quiere decir *es igual a*, y `<>` quiere decir *es distinto de*.

## Comparar

| Signo | Quiere decir |
|---|---|
| `=` | es igual a |
| `<>` | es distinto de |
| `<` | es menor que |
| `>` | es mayor que |
| `<=` | es menor o igual que |
| `>=` | es mayor o igual que |

```basic keys=7,Enter
10 INPUT "¿TU NOTA, DE 0 A 10? "; M
20 IF M >= 5 THEN PRINT "HAS APROBADO"
30 IF M < 5 THEN PRINT "SIGUE INTENTANDOLO, LO CONSEGUIRAS"
```

## THEN y un número de línea

Detrás de `THEN` puede ir un número de línea: si es verdad, el ordenador
salta allí. Así se hace un bucle que termina.

```basic keys=3,Enter,4,Enter
10 INPUT "¿CUANTO ES 2 + 2? "; A
20 IF A = 4 THEN 50
30 PRINT "PRUEBA OTRA VEZ"
40 GOTO 10
50 PRINT "¡SI! 2 + 2 = 4"
```

## ELSE

`ELSE` dice qué hacer cuando no es verdad, en la misma línea.

```basic keys=PECES,Enter
10 INPUT "¿QUE COMEN LOS PINGÜINOS? "; F$
20 IF F$ = "PECES" THEN PRINT "¡QUE RICO!" ELSE PRINT "NO, ¡PECES!"
```

> [point] Las palabras se comparan letra a letra, con sus mayúsculas:
> `peces` no es `PECES` para el ordenador.

## Sigue probando

- Una tienda: un pez cuesta 3 monedas. Pregunta cuántas monedas tiene el
  niño y di si le llega para un pez.
- Un concurso de tres preguntas, con una puntuación que crece con cada
  acierto.
- Cambia el programa de contar del capítulo anterior para que se pare en
  100.

::: adult
`IF … THEN` es donde un programa empieza a pensar. Cuando el programa de
un niño hace algo que no esperaba, pregúntele qué valía la condición en
ese momento; escribir los valores con `PRINT` es como lo averiguan los
programadores.
:::
