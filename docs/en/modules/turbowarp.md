# TurboWarp

*[Versión en español](../../es/modules/turbowarp.md)* · [Back to the user guide](../user-guide.md#9-learning-modules)

**TurboWarp** is a high-performance alternative to Scratch featuring an optimised Just-in-Time JavaScript compiler. It shares the exact same block interface and project formats as Scratch, but runs games, scripts, and animations with substantially higher framerates.

| | |
|---|---|
| **Recommended age** | Children and youths from 8 to 16 years old |
| **Recommended before** | ScratchJr |
| **Internet connection** | Optional (only required when downloading sprites, backgrounds, and sounds from the official library; coding and project playback are fully offline) |
| **Software used** | [TurboWarp](https://turbowarp.org/), developed by the open source TurboWarp project under the GPL-3 licence, packaged for offline execution in Kidux |

## What it is and how it works

TurboWarp is the ideal choice for older computers, lower-powered laptops, or complex programming projects where standard Scratch exhibits stutter or lagging framerates. Children accustomed to Scratch will find tools, palettes, and block categories in their exact familiar locations.

In addition to superior execution speed, TurboWarp provides handy customisation options, such as enabling smooth 60 frames-per-second motion, custom stage resolutions, and developer debugging toggles.

## Included features

- **Familiar interface**: identical workspace layout to Scratch with complete access to all standard coding blocks, costumes, and sounds.
- **Official asset library**: optional on-demand downloads of official Scratch sprites, audio effects, and backgrounds.
- **Compiled performance**: buttery-smooth execution powered by an internal JIT compiler.
- **Advanced options**: configurable simulation framerates, interpolation, and stage sizing.

## Saving projects and compatibility

Project management is identical to Scratch: click **File > Save to your computer** to save projects in the standard `.sb3` format into the child's documents folder. To resume editing, use **File > Load from your computer**.

Projects are 100% interoperable: any `.sb3` file saved in Scratch opens flawlessly in TurboWarp, and vice versa. For online child safety, downloading public shared projects by ID number from the central Scratch community is disabled; all work is loaded and stored through local project files.
